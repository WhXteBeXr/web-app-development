# Лабораторная работа № 3 - шаблоны и админка

Общий код находится в `Project/`. В методичке этой работы нет отдельных вариантов, уровней и контрольных вопросов.

Команды из корня репозитория:

```bash
source .venv/bin/activate
python Project/manage.py migrate
python Project/manage.py shell < lab2/demo.py
python Project/manage.py shell < lab3/demo.py
python Project/manage.py createsuperuser
python Project/manage.py runserver 127.0.0.1:8002
```

Если суперпользователь уже есть, повторно создавать его не нужно. Выберите собственные имя и пароль при интерактивном запуске команды. Данные тестового администратора, использованного при проверке, в рабочую базу не добавлялись.

- `/news/` - новости из базы через HTML-шаблон, новые записи сверху.
- `/news/test/` - проверочная страница первой работы.
- `/admin/` - вход администратора.
- `/admin/news/news/` - список новостей, поиск, добавление и редактирование.
- `/admin/news/comment/` - комментарии второй работы.

В ленте показываются все учебные записи, включая неопубликованные, с явной подписью статуса. Отбор по публикации в этой методичке не задан. Заголовки и текст экранируются, фотография необязательна.

Для демонстрации добавьте новость без фотографии, измените текст, найдите ее по слову в заголовке или содержании. Обновите ленту, затем удалите пробную запись через подтверждение в админке.
