# Лабораторная работа № 5 - оформление, теги и фильтры

В этой методичке нет вариантов и уровней. Выполнена вся практическая часть в общем Django-проекте.

Из корня репозитория:

```bash
source .venv/bin/activate
python Project/manage.py migrate
python Project/manage.py shell < lab2/demo.py
python Project/manage.py shell < lab3/demo.py
python Project/manage.py shell < lab4/demo.py
python Project/manage.py shell < lab5/demo.py
python Project/manage.py runserver 127.0.0.1:8002
```

Если предыдущие учебные данные уже есть, достаточно выполнить `lab5/demo.py`. Для этого задания новые миграции не требуются.

- `/news/` - карточки Bootstrap, категория, нумерация, чередование цветов, дата и статус.
- «Подробнее» - полный текст отдельной новости.
- «Добавить новость» - существующая форма админки, требующая входа.
- Мобильная кнопка раскрывает меню на узком экране.

Демонстрация добавляет одну новость из 101 слова. В карточке показаны первые 50 слов, на отдельной странице весь текст. Повторный запуск не дублирует исходный пример и не перезаписывает его пользовательские изменения.

Bootstrap 5.3.9 загружается через CDN. Локальные стили и заглушка находятся в `Project/news/static/news/`. Для загрузки Bootstrap браузеру нужен доступ к CDN. Фотографии сайта по-прежнему хранятся в `Project/uploads/`.
